# Portfólio — Daniel David Fernandes

Site estático responsivo feito com HTML, CSS e JavaScript puro, pronto para hospedagem no GitHub Pages.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `styles.css`: identidade visual e responsividade.
- `script.js`: menu mobile e ano automático.

## Como visualizar
Abra `index.html` no navegador. Para publicar, substitua os arquivos do repositório `danieldavidf.github.io` pelos arquivos deste projeto e faça o push para a branch configurada no GitHub Pages.
